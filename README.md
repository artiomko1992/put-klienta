# Client Path — prototype

A clickable prototype of a client-management system: projects as a pipeline, block acceptance with ok / ok with a question / not ok buttons, a promise registry, weekly hours and an admin panel.

- All clients, figures and employees are made up.
- Data is stored only in your browser (localStorage). Download a backup copy in the "Data" section.
- It can be installed on a phone as an app and opens without internet.

Install: iPhone — Safari → "Share" → "Add to Home Screen". Android — Chrome → ⋮ menu → "Install app".
